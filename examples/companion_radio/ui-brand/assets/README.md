# HaldenFunk T-Deck Standalone-Bootmotiv

Quelle: `logo/haldenfunk-display.png` in diesem Repository (HaldenFunk-Artwork).

`python3 tools/gen_tdeck_splash.py` erzeugt daraus RGB565 little endian, 320 × 213 Pixel und 136320 Bytes. `--check` vergleicht die erzeugte Datei. Die Firmware bindet ausschließlich diese generierte HaldenFunk-Grafik ein.
